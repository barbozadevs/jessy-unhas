# Jessy Unhas — Site Oficial

Site estático premium para salão/alongamento de unhas, inspirado no visual editorial do portfólio de referência enviado.

## Estrutura
- `index.html` — conteúdo e seções
- `styles.css` — visual, responsividade e animações
- `script.js` — menu, animações de entrada e avaliações com localStorage
- `assets/` — espaço para fotos reais dos trabalhos

## Colocar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie todos os arquivos mantendo a estrutura.
3. Em **Settings → Pages**, selecione `Deploy from a branch`, branch `main` e pasta `/root`.
4. Salve e aguarde o GitHub Pages publicar.

## Personalização rápida
- Troque `R$ 00,00` pelos preços reais.
- Troque os textos de localização pelo endereço real.
- Substitua os blocos visuais da galeria por fotos reais.
- WhatsApp configurado para `11 96261-2690`.
- Instagram configurado para `@jessytorres.148`.

## Avaliações
O sistema atual permite nota de 1 a 5 estrelas e comentário e salva no navegador via `localStorage`. Para avaliações compartilhadas entre todas as clientes, conecte um backend/banco (Supabase, Firebase ou API própria).
